# projects项目经历

Final Year Project毕业设计

Network-Based Intelligent Intrusion Detection System基于网络的智能入侵检测系统

2025 – 2026

An ML intrusion detection system trained on the CICIDS2017 dataset. It sorts network flows into benign, DoS/DDoS, port scan and brute force, and explains why each flow was flagged.

基于 CICIDS2017 数据集训练的机器学习入侵检测系统，可将网络流量分类为正常、DoS/DDoS、端口扫描与暴力破解，并解释每条流量被标记的原因。

99.86%Accuracy准确率
0.995Macro F1宏平均 F1
0.9998ROC-AUC
4Models compared对比模型
  • Built a leak-free pipeline: feature selection fitted on the training split only, and SMOTE applied inside stratified k-fold CV.
  • Compared four ways of handling class imbalance (class weights, SMOTE, SMOTE+Tomek, undersampling) and picked the best by macro-F1.
  • Added SHAP explanations for each alert, and mapped the top features to known indicators of compromise.
  • Tuned the detection threshold and tracked false-positive rate per class, then benchmarked against Decision Tree, Naive Bayes and Logistic Regression.
  • 构建无数据泄漏的流程：特征选择仅基于训练集，SMOTE 在分层 K 折交叉验证内部执行。
  • 对比四种类别不平衡处理方法（类别权重、SMOTE、SMOTE+Tomek、欠采样），以宏平均 F1 选出最优方案。
  • 通过 SHAP 为每条告警提供解释，并将关键特征映射到已知入侵指标（IoC）。
  • 调整检测阈值、追踪各类别误报率，并与决策树、朴素贝叶斯及逻辑回归模型进行基准对比。
